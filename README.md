# 天津地铁模组

一个 [Minecraft Transit Railway](https://github.com/jonafanho/Minecraft-Transit-Railway) 的附属模组，处于开发阶段。

## 构建步骤

1. 克隆仓库
2. 同步 Gradle 项目
3. 切换 Minecraft 版本 / 初次运行时：
   1. 同步 Gradle 项目
   2. 运行根项目 Gradle 的 `setupLibrary` 任务
   3. 再次同步 Gradle 项目
